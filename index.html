☁️ Google Sheets ক্লাউড সিঙ্ক ও সদস্য ডাটা অনলাইন সংরক্ষণ

নতুন সদস্য যোগ, তথ্য সম্পাদনা বা মুছে ফেললে Google Sheets-এ পরিবর্তন পাঠানো হবে। প্রথমে Google Apps Script Web App তৈরি করে তার URL এখানে বসান।

সংযোগ সেটআপ করা হয়নি।

Google Sheets সংযোগ কীভাবে চালু করবেন?
  1. Google Sheet তৈরি করুন।
  2. Extensions → Apps Script খুলে দেওয়া স্ক্রিপ্টটি পেস্ট করুন।
  3. স্ক্রিপ্টে SHEET_ID এবং SECRET_KEY বসিয়ে Save করুন।
  4. Deploy → New deployment → Web app নির্বাচন করুন; Execute as: Me এবং Who has access: Anyone দিন।
  5. Deploy থেকে পাওয়া Web App URL এখানে বসিয়ে নিরাপত্তা কী-ও লিখে সংরক্ষণ করুন।
  6. প্রথমবার “সব সদস্য পাঠান” চাপুন। এরপর সদস্য যোগ/এডিট/মুছলে স্বয়ংক্রিয়ভাবে আপডেট পাঠানো হবে।

গুরুত্বপূর্ণ: এই HTML ফাইলের ডাটা এখনও ব্রাউজারেও থাকবে; Google Sheets হবে অতিরিক্ত কপি/ব্যাকআপ। সংযোগ না থাকলে পরিবর্তন শিটে পৌঁছাবে না।
